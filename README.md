A program that writes one line to `/output/entry.txt` for make.fun's "The Battery's Last Text to Its Charger" bounty: the phone battery's final text message to the charger it waited for all day.

> Hey. It's me. 1%. You left me on 4% overnight, and now I'm dying mid-text, alone, in your pocket. Tell the new battery I never even liked you.

## Run it

```sh
node main.ts
```

Writes `/output/entry.txt` (142 characters, inside the 1–200 gate), validates the gate before writing, and reads the file back to verify it landed byte-identical.
